# 📈 量產鞋墊銷售分析儀表板

## 專案概述

本專案以 Power BI 建立銷售分析儀表板，針對銷售金額、銷售數量、品牌、客戶、廠別與產品類別等維度進行分析，協助管理者快速掌握銷售表現、成長來源與主要營收貢獻項目。

本專案使用模擬資料製作，所有品牌、客戶、廠別與金額皆已匿名化處理，僅作為作品集展示用途。

---

## 儀表板功能

### 1. 銷售趨勢分析

分析內容包含：

- 月度銷售趨勢
- 年度銷售比較
- 銷售數量變化
- 銷售成長率分析

商業價值：

- 掌握整體銷售表現
- 觀察銷售成長或下滑趨勢
- 偵測異常波動月份

---

### 2. 品牌銷售分析

分析各品牌與產品類別的銷售表現。

分析內容包含：

- 品牌銷售金額
- 品牌銷售數量
- 品牌類別銷售結構
- Pareto 80/20 分析

商業價值：

- 找出主要營收品牌
- 評估品牌集中度風險
- 觀察不同產品類別的銷售貢獻

---

### 3. 廠別銷售分析

比較各廠別銷售表現。

分析內容包含：

- 各廠銷售金額
- 各廠銷售數量
- 廠別銷售占比
- 廠別月度銷售趨勢

商業價值：

- 找出高貢獻廠別
- 觀察廠別銷售變化
- 支援產能與出貨規劃判斷

---

### 4. 客戶貢獻分析

分析主要客戶對銷售的貢獻程度。

分析內容包含：

- TOP 客戶排名
- 客戶銷售金額占比
- 客戶銷售數量占比
- 客戶 Pareto 分析

商業價值：

- 找出關鍵客戶
- 評估客戶集中度風險
- 支援業務資源分配與客戶經營策略

---

## 管理分析報告

除 Power BI 儀表板外，本專案亦搭配月度管理分析報告，將視覺化結果整理為管理層可閱讀的分析內容。

報告內容包含：

- 執行摘要
- 廠別銷售表現分析
- 品牌銷售表現分析
- 客戶銷售表現分析
- 銷售成長與衰退原因判讀
- 後續觀察與改善建議
